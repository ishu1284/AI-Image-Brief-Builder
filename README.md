# PromptFrame

A free, static AI product-image prompt builder for designers and small e-commerce teams.

## How it works

Open `index.html` in a browser. Set product, visual direction, lighting, setting, aspect ratio and locked product details. Copy or download the generated prompt. No API key, backend or build step required.

## Deploy with Vercel

Import the GitHub repository `ishu1284/AI-Image-Brief-Builder` at https://vercel.com/new. Choose **Other** as the framework preset, leave the build command empty, set the output directory to the project root (or leave its default for a static site), and deploy.

## User validation

Ask a designer or seller to generate a real prompt and get permission before quoting their use in a public portfolio or application.

## Limitations

PromptFrame creates text prompts; it does not generate images or guarantee that models preserve source product details.
